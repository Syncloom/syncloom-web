# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [semantic versioning](https://semver.org/). Syncloom is a public preview until 1.0.

## [0.1.0] - 2026-11-02

First public preview.

### Added
- Browser app on SvelteKit: sign-up and sign-in with TOTP and security keys, file browser, upload, preview, download, trash and versions.
- Key/value editor, shares and public links, settings and admin pages.
- Encryption runs locally through the WebAssembly build of the core. Live updates over gRPC-Web.
- Real-browser test suite (Playwright).
